# DSA Java Repository

A structured, beginner-to-intermediate collection of **Data Structures and Algorithms in Java**, organized into five learning units.

> Learn the concept → study the implementation → run the program → solve the practice tasks.

## Repository map

| Unit | Focus | Topics |
|---|---|---|
| 01 | Foundations | Complexity, arrays, strings, matrices |
| 02 | Linear data structures | Linked lists, stacks, queues, recursion |
| 03 | Non-linear data structures | Trees, BST, heaps, hashing |
| 04 | Graph algorithms | Graph representation, BFS, DFS, shortest paths |
| 05 | Algorithm design | Searching, sorting, greedy, dynamic programming |

Each topic folder contains Java source files and a short README where useful. Programs use standard Java and do not require external libraries.

## Requirements
- JDK 17 or later (most examples also work on JDK 8+)
- Terminal, IntelliJ IDEA, Eclipse, or VS Code with Java extensions

Check Java installation:
```bash
java -version
javac -version
```

## Run a program
```bash
cd Unit-01-Foundations/Arrays
javac ArrayTraversal.java
java ArrayTraversal
```

Current examples intentionally avoid package declarations so individual practice files are easy to run.

## Suggested learning order
1. Start with arrays, strings, and matrices.
2. Learn linked lists, stacks, queues, and recursion.
3. Move to trees, heaps, and hash maps.
4. Practice graph traversal and shortest paths.
5. Finish with sorting, searching, greedy methods, and dynamic programming.

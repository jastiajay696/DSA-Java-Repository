# Practice Problems

Try these without looking at the solutions first. Add your own .java files here, grouped by difficulty.

## Beginner
1. Find the minimum and maximum in an array.
2. Count vowels and consonants in a string.
3. Check whether two strings are anagrams.
4. Implement a stack using two queues.

## Intermediate
5. Detect a cycle in a linked list.
6. Find the height of a binary tree.
7. Check whether a graph is bipartite.
8. Find the first and last occurrence of a target in a sorted array.

## Advanced
9. Find the longest increasing subsequence.
10. Solve the 0/1 knapsack problem.
11. Find strongly connected components in a directed graph.
12. Implement a trie with insert and search operations.

For each solution, document the approach, complexity, and at least two test cases.

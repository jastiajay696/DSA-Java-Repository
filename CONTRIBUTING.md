# Contributing

Thanks for helping improve this Java DSA collection.

## Guidelines
1. Keep each example focused on one concept.
2. Use descriptive class and file names.
3. Include comments where logic may not be obvious.
4. Validate input where practical and handle edge cases.
5. Add a short explanation and sample input/output for substantial new topics.
6. Avoid external dependencies unless absolutely necessary.

## Before submitting
- Compile changed Java files with a supported JDK.
- Run each program with normal and edge-case inputs.
- Describe the algorithm and time/space complexity in pull requests.
